Política de privacidade do Devbox

Última atualização: 6 de outubro de 2026.

Quais dados o Devbox acessa

  • Gmail (escopo gmail.modify): ler, organizar (marcar como lido, arquivar, aplicar marcadores) e enviar e-mails da conta do próprio usuário.
  • Google Agenda (escopo calendar.readonly): ver os eventos das agendas do usuário. O Devbox não cria nem altera eventos.
  • Identidade básica (openid, email): saber qual conta está conectada.

Como os dados são usados

Os dados são usados apenas para exibir e organizar os e-mails e a agenda do usuário dentro do aplicativo, na máquina dele. O Devbox não tem servidor próprio: nada é enviado, armazenado ou compartilhado com o desenvolvedor ou com terceiros. Os tokens de acesso ficam guardados localmente no computador do usuário.

O uso de informações recebidas das APIs do Google obedece à Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O usuário pode desconectar o Devbox a qualquer momento em myaccount.google.com/permissions. Apagar o app remove os dados locais.
